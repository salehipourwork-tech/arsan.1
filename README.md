# آرسان — دستیار هوشمند تحلیل رمزارز

راهنمای گام‌به‌گام راه‌اندازی (مخصوص کسی که برنامه‌نویس نیست)

## چیزی که در این پوشه داری

- `analyzer/` → کدهای پایتون که داده می‌گیرند، تحلیل تکنیکال انجام می‌دهند و تصمیم می‌گیرند.
- `.github/workflows/analyze.yml` → دستور خودکار که هر ۱ ساعت این تحلیل را اجرا می‌کند (رایگان، روی سرور گیت‌هاب، بدون نیاز به روشن بودن لپ‌تاپ تو).
- `index.html` → صفحه وب آرسان (داشبورد).
- `data/analysis.json` → جایی که آخرین نتیجه تحلیل ذخیره می‌شود.

## مرحله ۱: ساخت حساب گیت‌هاب (فقط یک بار، رایگان)

1. به آدرس https://github.com/signup برو و یک حساب رایگان بساز.

## مرحله ۲: ساخت یک Repository جدید

1. بعد از ورود، روی دکمه سبز **New** کلیک کن.
2. اسم Repository را بگذار: `arsan`
3. آن را **Public** انتخاب کن (برای اینکه GitHub Pages رایگان کار کند).
4. روی **Create repository** کلیک کن.

## مرحله ۳: آپلود فایل‌های پروژه

ساده‌ترین روش بدون خط فرمان:

1. داخل صفحه Repository که ساختی، روی لینک **uploading an existing file** کلیک کن.
2. تمام فایل‌ها و پوشه‌های داخل این پکیج (که از من دریافت کردی) را با حفظ ساختار پوشه‌ها بکش و رها کن.
   (مرورگرها معمولاً پوشه‌ها را هم قبول می‌کنند؛ اگر قبول نکرد، به من بگو تا روش جایگزین با Git بدهم.)
3. پایین صفحه روی **Commit changes** کلیک کن.

## مرحله ۴: فعال‌سازی اجرای خودکار (GitHub Actions)

1. در Repository به تب **Actions** برو.
2. اگر پیام تایید ظاهر شد، گزینه فعال‌سازی Workflow را بزن.
3. روی workflow با نام **Arsan Market Analysis** کلیک کن، سپس دکمه **Run workflow** را بزن تا اولین تحلیل به‌صورت دستی اجرا شود (حدود ۱ تا ۲ دقیقه طول می‌کشد).
4. بعد از این مرحله، این کار به‌صورت خودکار هر ۱ ساعت یک‌بار برای همیشه تکرار می‌شود — بدون نیاز به هیچ کاری از طرف تو.

## مرحله ۵: فعال‌سازی وب‌سایت (GitHub Pages)

1. به تب **Settings** در Repository برو.
2. از منوی سمت چپ گزینه **Pages** را انتخاب کن.
3. زیر «Build and deployment» → «Source» گزینه **Deploy from a branch** را انتخاب کن.
4. Branch را روی `main` و پوشه را روی `/ (root)` بگذار، سپس **Save** کن.
5. بعد از حدود ۱ دقیقه، آدرس سایتت این شکلی می‌شود:
   `https://USERNAME.github.io/arsan/`
   (به‌جای USERNAME نام کاربری گیت‌هاب خودت را بگذار)

## همین! 🎉

از این به بعد:
- هر ساعت، آرسان به‌صورت خودکار داده‌های بازار را می‌گیرد و تحلیل می‌کند.
- تو هر زمان بخواهی فقط وارد آدرس سایت می‌شوی و آخرین تحلیل را می‌بینی.
- لپ‌تاپ تو نباید روشن باشد — همه چیز روی سرورهای رایگان گیت‌هاب اجرا می‌شود.

## نکات مهم

- منبع داده: **CoinGecko** (رایگان، بدون نیاز به API Key صرافی).
- اگر بخواهی رمزارز جدیدی اضافه شود، کافی است در فایل `analyzer/fetch_data.py`
  داخل لیست `DEFAULT_COINS` یک خط جدید اضافه کنی (بگو من هم می‌توانم این کار را برایت انجام دهم).
- علاقه‌مندی‌ها (⭐) در همان مرورگر تو ذخیره می‌شود.

## اگر با مشکلی مواجه شدی

هر خطایی که در تب Actions دیدی، یا هر بخشی که کار نکرد، اسکرین‌شات بگیر یا متن خطا را برایم بفرست — من همان‌جا برایت اصلاحش می‌کنم.
