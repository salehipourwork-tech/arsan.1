# نکته‌ی مهم درباره‌ی pandas_ta:
# پکیج اصلی pandas_ta/pandas-ta چند ماهه از PyPI و حتی از مخزن اصلی
# گیت‌هابش (twopirllc/pandas-ta) به‌طور کامل حذف شده (ماجرای عوض‌شدن
# مالکیت/maintainer که در Issue های خودِ پروژه هم ثبت شده) — برای همین
# `pip install pandas_ta` دیگر هیچ نسخه‌ای پیدا نمی‌کند (خطای
# "No matching distribution found"). این ربطی به کد RSP ندارد.
# جایگزین قابل‌اعتماد: یک fork آینه (mirror) از همان کد قبل از حذف، که
# دقیقاً همان نام import (`import pandas_ta as ta`) را حفظ کرده — پس
# نیازی به تغییر هیچ فایلی در RSP/ نیست. به یک commit مشخص پین شده تا
# در آینده هم رفتار یکسان و تکرارپذیر بماند. numpy را خودِ این پکیج روی
# 1.26.4 قفل می‌کند (نسخه‌ی سازگار شناخته‌شده با آن)، پس numpy را جدا
# لیست نکردیم تا با آن تداخل نکند.
